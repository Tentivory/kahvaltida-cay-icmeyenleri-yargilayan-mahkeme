# 🍵 Kahvaltıda Çay İçmeyenleri Yargılayan Mahkeme 🍵

## Resmi Açıklama

Bu repository, insanlık tarihinin en önemli adalet sistemlerinden birini içerir. Kahvaltıda çay içmemek, sadece bir tercih değil, toplumsal düzenin temel taşlarından birine saldırıdır. Bu mahkeme, bu suçu işleyenleri adil, şeffaf ve biraz da dramatik bir şekilde yargılar.

**Uyari:** Bu kod gerçekten çalışır. Mahkemeye çıkmadan önce çay içmeyi düşünün.

## Nasıl Çalışır?

1. Python 3 ile `mahkeme.py` dosyasını çalıştırın.
2. Mahkeme size kahvaltıda çay içip içmediğinizi sorar.
3. Cevabınıza göre beraat veya hüküm alırsınız.
4. Adalet yerini bulur. Ya da bulmaz. Ama çay içilir.

## Kurulum

```bash
git clone https://github.com/Tentivory/kahvaltida-cay-icmeyenleri-yargilayan-mahkeme.git
cd kahvaltida-cay-icmeyenleri-yargilayan-mahkeme
python3 mahkeme.py
```

## Özellikler

- ✅ Gerçek zamanlı yargılama
- ✅ Rastgele cezalar (adil mi? Tartışılır)
- ✅ Dramatik bekleme süreleri
- ✅ %100 Türkçe adalet
- ✅ Çay sevgisi garantili

## Lisans

Bu proje, Kahvaltı Çayı Anayasası'na göre lisanslanmıştır. Çay içmeyenler kullanamaz. Çay içenler de kendi sorumluluğundadır.

## Katkıda Bulunma

Pull request açabilirsiniz ama mahkeme onaylamayabilir. Çay ikram etmeyi unutmayın.
